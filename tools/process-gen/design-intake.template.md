# 流程設計需求單（填空版）

**用法**：複製這份檔案（例如存成 `design-我的App.md`），照著填。不用懂 JS、不用懂 kintone 的 JSON 結構，
純中文回答就好。填完把整份檔案內容貼給 Claude，說「幫我把這份需求單轉成 spec.js」，
就會產出可以直接 `node generate.js` 的規格檔。

填之前先做一件事：**執行 `node lookup.js --app <你的App ID>`**，把印出來的欄位代碼、群組代碼記下來，
下面表格裡的「處理人」欄要填的就是那份清單裡的東西。

## 二、狀態設計（每個簽核關卡填一組）

複製下面這個區塊，一個關卡填一份，需要幾關就複製幾份。

```
### 狀態：__________（例：申請單位主管確認）

- 誰來處理這一關？
  □ 表單上的「選擇使用者」欄位 → 欄位名稱：__________（對照 lookup.js 的①表）
  □ 表單上的「組織選擇」欄位 → 欄位名稱：__________（依記錄選到的組織動態指派）
  □ 表單上的「群組選擇」欄位 → 欄位名稱：__________（依記錄選到的群組動態指派成員，跟下面「固定群組」不同）
  □ 固定群組（後臺設定，所有記錄都一樣）→ 群組名稱：__________（對照 lookup.js 的②表）
  □ 固定組織（後臺設定，所有記錄都一樣）→ 組織名稱：__________（對照 lookup.js 的③表）
  □ 記錄建立人 / 更新人

- 這一關的處理方式？（群組、組織、或「可選多人的使用者欄位」都適用這題）
  □ 指定一人（ONE，預設）　□ 其中任何一人處理即可（ANY）　□ 全部的人都要處理（ALL）

- 這一關需要「駁回」按鈕嗎？
  □ 需要 → 駁回後退回哪個狀態？（通常是「草稿」）__________
  □ 不需要（例如最後核准關卡，駁回等於直接作廢，或這關本身就是駁回狀態）

- 這是「終點狀態」嗎？（例如流程結束、表單作廢——不會再被簽核，通常不設處理人）
  □ 是　□ 否
```

**已經有的狀態範例（照抄格式即可）：**

```
### 狀態：草稿（未送出）
- 誰來處理：表單上的「選擇使用者」欄位 → 欄位名稱：申請人
- 群組模式：不適用（ONE）
- 需要駁回：否（這是流程起點，駁回會回到這裡，不是從這裡駁回）
- 是否終點：否

### 狀態：申請單位主管確認
- 誰來處理：表單上的「選擇使用者」欄位 → 欄位名稱：單位主管
- 群組模式：ONE
- 需要駁回：是 → 退回「草稿（未送出）」
- 是否終點：否

### 狀態：流程結束
- 誰來處理：（終點狀態，留空）
- 需要駁回：否
- 是否終點：是
```

## 三、流程走向（誰簽完之後，下一關給誰）

一樣複製一份填一組。「條件」欄可以完全用白話講，不用寫 kintone 查詢語法，
交給 Claude 轉換時會處理成正確的 filterCond。

```
- 從狀態：__________　按下按鈕：__________　到狀態：__________
- 觸發條件（白話描述，例：「當金額大於等於 1 萬」「當申請人的部門是總務部」；若永遠都能按，寫「無條件」）：
  ______________________________________________
- 這顆按鈕是主要按鈕，還是收在「⋯更多」選單裡？
  □ 主要　□ 更多選單
- 有沒有限定「只有特定人／群組」才能按這顆按鈕？（不填 = 目前處理人都能按）
  ______________________________________________
- 這是開發測試用的臨時按鈕嗎？（上線前會自動移除）
  □ 是　□ 否
```

**已經有的走向範例：**

```
- 從狀態：草稿（未送出）　按下按鈕：提交_申請單位主管確認　到狀態：申請單位主管確認
- 觸發條件：當單位主管欄位裡的人屬於「課長」群組，且申請人不屬於總務課
- 主要按鈕
- 無限定執行人
- 非測試用

- 從狀態：草稿（未送出）　按下按鈕：測試　到狀態：流程結束
- 觸發條件：無條件
- 更多選單
- 限定「開發人員」群組才能按
- 是測試用（上線前移除）
```

> 如果同一個狀態要分岔到不同去處（例如「金額 < 1 萬走 A、金額 >= 1 萬走 B」），
> 就填兩組「從狀態」相同、「觸發條件」互補的走向，用不同的白話條件描述清楚分岔規則即可。

## 四、駁回的共通規則（整個流程只填一次）

```

- 駁回按鈕的名稱統一叫「駁回」嗎？
  □ 是　□ 否，叫：__________

- 從駁回狀態要「再申請」時，按鈕名稱與回到的狀態？
  按鈕名稱：__________（預設「再申請」）　回到狀態：__________（預設「草稿」）
```

  ______________________________________________
